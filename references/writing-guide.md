# 写作与排版默认风格

这些是天启云AI 的默认偏好；用户本次指定的受众、文风、品牌和篇幅优先。作者、商品 ID 与商品名称从 `config/defaults.json` 读取。

## 内容

- 默认约 1000 字，用大白话，像向朋友解释一件事；每篇解决一个主要痛点。
- 技术话题尽量解释读者能做什么、会得到什么，减少读者不需要的实现术语。
- 默认内容方向为 GPT、Codex、AI 工具和工作效率；根据用户主题调整。
- 数据、效果和真实案例需要来源。原创示例写成“你可以这样说”，不虚构客户经历、收益或成功率。
- 标题默认采用“痛点 + 数字”或“XX 前先 XX”，简短清楚；脚本检查 64 UTF-8 字节上限。
- 商品名称和卖点需要用户资料或商品信息支撑；价格与服务内容以实际商品页面为准。换商品时同步修改正文推广文案。

## 默认结构

1. 用读者会问的一句话引出痛点。
2. 用绿色结论卡给出一句话结果。
3. 用绿色左边框小标题分步解释，适当给出可直接使用的例子。
4. 用黄色卡说明适合谁，给出实际限制。
5. 需要商品时写自然的引导语，保留一个 `<!--PRODUCT_CARD-->`；无需商品时省略整个推广段。
6. 用一句关注引导结束。

`assets/article-template.html` 是这个结构的起点，可以按用户要求调整分节数量和文字，保留微信兼容的样式。

## 微信排版

- 全部使用内联样式；小标题和卡片使用模板颜色。
- 正文默认 16px、行高 1.85、颜色 `#333`、段首缩进 `2em`；卡片与示例段落不缩进。
- 列表用带序号的 `<p>`，避免依赖复杂列表样式。
- 正文如包含图片，需要微信可用的素材地址；本技能默认只有独立封面，正文图片上传不是当前脚本功能。

## 封面

默认采用笔记本纸张、黑色手写主文案和荧光笔重点。只放一句主文案，保持手机小图可读。文字位于图像中央横带，检查生成的中文和裁剪后的标题完整性。

用户已有封面时直接使用；新图按 `SKILL.md` 使用内置 ImageGen。裁剪输出为 900×383，不把移除水印作为处理目标。
